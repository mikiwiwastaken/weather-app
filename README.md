# Weather App

A small browser-based weather dashboard built with plain HTML, CSS, and JavaScript.

## Features

- Search by city name
- Show current weather details and conditions
- Toggle between Celsius and Fahrenheit
- Save recent searches and preferred unit in local storage

## Run locally

1. Open `index.html` in a browser, or
2. Serve the project with a small local web server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
